Terraform and Kubernetes Deployment on AWS

This project demonstrates infrastructure provisioning with Terraform and application deployment using Kubernetes. It uses Nginx as a sample application and is part of my hands-on DevOps learning journey.

The goal is to practice Infrastructure as Code (IaC), container orchestration, Kubernetes deployments, and cloud infrastructure management.

Technologies Used

AWS EC2 — Cloud compute infrastructure

Terraform — Infrastructure as Code

Kubernetes (k3s) — Lightweight Kubernetes cluster

Nginx — Web server application

YAML — Kubernetes resource configuration

Git and GitHub — Version control and source code management

Linux / Ubuntu — Command-line administration

Project Structure

terraform-docker/
├── .gitignore
├── main.tf
└── deployment.yaml

Features

Infrastructure configuration using Terraform

Kubernetes deployment of Nginx

Deployment configured with three replicas
Kubernetes written in YAML

Version tracking with Git

Practical experience with cloud infrastructure and container orchestration
